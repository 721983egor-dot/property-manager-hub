# Property Manager Hub

Создай веб-приложение с названием RM OS.

Это внутренняя система управления компанией, которая занимается долгосрочной арендой недвижимости.

На данном этапе нужно создать только один раздел — «Объекты».

Не создавай пока календарь, арендаторов, договоры, платежи, аналитику и другие разделы.

Общий интерфейс

Сделай современный минималистичный интерфейс SaaS/CRM-системы.

Стиль:

светлый фон;

много свободного пространства;

аккуратная типографика;

тонкие разделители;

небольшие скругления;

минимальное количество декоративных элементов;

интерфейс должен выглядеть профессионально и дорого;

основная версия — desktop.

Слева сделай вертикальное меню.

В верхней части меню:
RM OS

В меню пока только один активный пункт:
Объекты

Список объектов

Основной вид сделай в формате современной таблицы.

Каждый объект должен отображаться отдельной строкой.

Колонки:

Объект

Показывать:

главное фото;

название объекта;

ID объекта.

Тип

Например:
Квартира

Комплекс

Например:
ЖК Кислород

Этаж

Формат:
7/18

То есть:
этаж объекта / количество этажей в здании.

Планировка

Например:
2 комнаты

Санузлы

Количество от 1 до 5.

Статус

Статус отображать цветным бейджем.

Возможные статусы:

Свободен — зеленый
Сдан — спокойный синий
Забронирован — желтый или оранжевый
Архив — серый

Действия

Справа у каждого объекта:

иконка редактирования

и меню •••

В меню:

Редактировать

Переместить в архив

Если объект уже находится в архиве:

Восстановить объект

Не удалять объект из базы окончательно через основной интерфейс.

Добавление объекта

При нажатии на кнопку:

+ Добавить объект

Открывать отдельную страницу или большую форму.

Форма должна быть простой и визуально разбита на блоки.

Фотографии

отображается во вкладке «Архив»;

остается полностью сохраненным в базе;

его можно восстановить.
