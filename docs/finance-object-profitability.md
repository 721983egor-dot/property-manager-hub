# Прибыльность объектов

В «Финансы → Отчёты» по умолчанию открывается вкладка «Прибыльность объектов».
Фильтры: произвольные даты, месяц / прошлый месяц / квартал / год, дома / квартиры,
конкретный объект и существующая финансовая классификация. Виллы и таунхаусы
относятся к домам, апартаменты — к квартирам. Архивные объекты доступны для истории.

Расчёт общий для интерфейса и инструмента Ассистента `getObjectProfitability`:
`src/lib/finance-object-profitability.ts`. Ассистент проверяет доступ администратора
через существующий `crmAccess`, включая авторизованный Telegram-контекст.
Маршрут отчётов сохраняет `AdminOnly`, данные браузера читаются через существующие RLS.

Выручка и расходы берутся из существующего `reportEntries(..., "profit")`:
полные начисления по `accrual_date`, иначе `planned_date`, включая неоплаченные.
Из связанной аренды в выручку входит только комиссия компании. Депозиты,
КУ, выплаты собственнику, расходы за его счёт и исключённые из прибыли статьи
не входят в результат компании. Общие расходы без объекта не распределяются.
Платежи без найденного объекта исключены из этого отчёта, остаются в общих отчётах.

Начисленная гостям аренда и известная доля собственника — справочные колонки.
При неизвестной комиссии показывается предупреждение и сумма нераспределённой
аренды. Нулевая комиссия считается явным распределением целиком собственнику.
Рентабельность = прибыль / выручка компании; без выручки показывается «—».
Старые дубли комиссий исключаются существующим `bankPayments`.

Доступны рейтинг, сортировка, расшифровка по статьям и исходным операциям,
экспорт CSV выбранной выборки с итогами и суммой нераспределённой аренды.
При открытии комиссии редактируется исходный платёж аренды целиком.
Миграций, новых записей или изменения финансовых данных отчёт не требует.

Проверка 21 октября 2026: production build, ESLint изменённых файлов,
38 тестов моделей прибыли/аналитики/компании. В браузере на изолированных
данных проверены фильтры домов и квартир, конкретная квартира, квартал,
произвольные даты без начислений, сброс и расшифровка отрицательной прибыли.
TypeScript проекта содержит прежние ошибки схемы; новых диагностик в
добавленных компонентах, модели и инструменте нет.

Локальный стенд реального компонента: `http://127.0.0.1:4198/profitability.html`.
Служебные файлы находятся в игнорируемом `.finance-preview.local`.
Рабочая система в рамках этой задачи не развёртывается.
