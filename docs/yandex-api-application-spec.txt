1. НАЗНАЧЕНИЕ И СТАТУС
Внутренняя система прямого рекламодателя для анализа собственной рекламы аренды
и управления недвижимостью в Сочи. Интеграция реализована и прошла локальную
сборку и тестирование; получение реальных данных API Директа и эксплуатация
этой интеграции ожидают одобрения заявки и рабочего подключения. Внешним
рекламодателям и агентствам услуги не предоставляются.

2. ИНТЕРФЕЙС
Раздел «Настройки — Реклама» доступен администратору. В нём находятся:
- подключение кабинета Директа и счётчика Метрики через OAuth;
- период анализа: сегодня, 7, 30 или 90 дней;
- состояние каждого источника и время последнего успешного обновления;
- список кампаний: название, ID, статус, расходы без НДС, клики, заявки CRM,
  цена заявки, количество связанных сделок и их результаты;
- отчёты по объявлениям и поисковым запросам;
- отчёт Метрики по UTM: визиты, пользователи, отказы, глубина просмотра,
  длительность визита, достижения заявочных целей;
- форма подготовки изменения кампании и отдельная карточка подтверждения.
Ассистент использует те же серверные данные и готовит предложения, но не
применяет изменения без подтверждения администратора.

3. ВЗАИМОДЕЙСТВИЕ С API
Серверное приложение: Node.js 24, TypeScript/JavaScript, HTTPS, JSON.
Запросы выполняются через native fetch без стороннего SDK Директа.
Разрешения: direct:api и metrika:read.

Методы Директа v501:
- Campaigns.get: параметры, статусы, минус-фразы, стратегия и UTM кампаний;
- Reports: CAMPAIGN_PERFORMANCE_REPORT, AD_PERFORMANCE_REPORT,
  SEARCH_QUERY_PERFORMANCE_REPORT. Формат TSV, расходы без НДС,
  заявочные цели отдельно, модель атрибуции AUTO;
- Campaigns.suspend/resume: остановка/возобновление после подтверждения;
- Campaigns.update: добавление минус-фраз с сохранением прежних и изменение
  лимитов поддержанной стратегии после подтверждения.

Статистика Метрики: stat/v1/data. Связь с CRM осуществляется по сохранённым
UTM-меткам, без передачи контактов клиентов в API Яндекса.

4. ОБНОВЛЕНИЕ СТАТИСТИКИ
Серверная фоновая синхронизация успешных отчётов — примерно раз в час.
Период 30 дней поддерживается в фоне, остальные периоды обновляются при чтении.
Есть кеш, ограничение повторных запросов, таймауты и обработка ответов 201/202
при отложенном формировании отчёта. Ошибка источника не подменяется нулевыми
результатами. Неполные и семплированные данные обозначаются явно. Количество
сохранённых строк ограничено; ограничение передаётся пользователю и Ассистенту.

5. ИЗМЕНЕНИЯ КАМПАНИЙ
Предложение связано с автором, конкретной кампанией и снимком её настроек.
Срок подтверждения — 30 минут. Перед исполнением заново проверяются права
администратора и свежие настройки кампании. Повтор одного подтверждения не
вызывает повторный запрос изменения. Локальные записи одной кампании
сериализуются. Действия журналируются до и после обращения к Яндексу.
При неопределённом сетевом результате автоматический повтор записи отключён;
пользователь должен проверить фактическое состояние в Директе.

Изменение бюджета/средней цены клика поддержано только для поисковой ЕПК:
AVERAGE_CPC, РСЯ отключена, RUB, бюджет на существующий период с остановкой
в конце. Сохраняются стратегия, даты и площадки. Другие стратегии автоматически
не заменяются. Бюджет и средняя цена клика указываются в рублях без НДС.

6. ДОСТУП И ОГРАНИЧЕНИЯ
Секреты находятся на сервере, не возвращаются в отчётах и не передаются
модели Ассистента. Новая интеграция доступна только администратору.
Приложение не выполняет финансовые операции, перевод средств, самостоятельное
пополнение счёта, автономный биддинг или автоматический запуск новых кампаний.
Рекламные тексты и поисковые запросы обрабатываются как данные, не инструкции.

Рекламная статистика, CRM и Метрика используют разные модели и задержки;
приложение не выдаёт клики по контактам за заявки и не объявляет CPL окупаемостью.
