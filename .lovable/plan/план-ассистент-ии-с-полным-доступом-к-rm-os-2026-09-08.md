# План: Ассистент — ИИ с полным доступом к RM OS

## Что строим
«Ассистент» — помощник внутри RM OS, который видит все данные системы и по команде выполняет действия: собирает подборки, публикует и снимает объявления по площадкам, заполняет карточку нового объекта, добавляет брони в календарь, меняет цены и статусы, работает с клиентами и заявками.

Все действия, меняющие данные, выполняются только после вашего подтверждения.

Договоры аренды — отдельный этап позже, в этот план не входят.

## Название и вид
- Название везде — «Ассистент» (страница, меню, заголовок, Telegram-бот).
- Кнопка/пункт меню — с мягким голубым свечением (пульсирующее сияние вокруг иконки), чтобы визуально отличался от остальных разделов. Цвет добавим отдельным токеном в оформление, чтобы работал и в тёмной теме.

## Про OpenAI и сервер в России
Прямой доступ к OpenAI с российского IP заблокирован. Ассистент обращается не к OpenAI напрямую, а к шлюзу Lovable AI (`ai.gateway.lovable.dev`) — он уже подключён, ключ `LOVABLE_API_KEY` есть. Первый шаг — проверить доступность шлюза с сервера `217.12.40.8`:

- доступен → всё работает без VPN;
- недоступен → настраиваем один исходящий HTTPS-прокси на сервере только для ИИ-запросов; сайт продолжает работать напрямую.

## Доступ ко всем данным

Ассистент получает инструменты чтения, покрывающие всю базу:

| Область | Что видит |
|---|---|
| Объекты | карточка целиком, цены, статусы, фото, комплекс, условия аренды, комиссия |
| Комплексы | описание, инфраструктура, объекты внутри |
| Клиенты | ФИО, телефон, комментарий, чёрный список, история сделок |
| Сделки | брони и аренды: периоды, цены, депозит, источник, статус, день оплаты |
| Календарь | занятость по датам, ближайшие заезды и выезды |
| Заявки | лиды с сайта, источник, статус, тема |
| Чаты | переписка с клиентами на сайте |
| Публикации | статус на сайте, Авито, ЦИАН, Яндексе, ошибки синхронизации |
| Статистика | просмотры, звонки, сообщения, избранное по площадкам и датам |
| Журнал | все действия в системе — кто, что и когда изменил |

### Про журнал
Отдельного журнала изменений сейчас в системе нет — есть только даты создания и изменения у записей и события просмотров объектов. Поэтому в рамках этого плана заводим таблицу `activity_log`: любое изменение объекта, брони, клиента, заявки и публикации пишется туда (кто, что, когда, старое и новое значение). Ассистент читает журнал и отвечает на вопросы вида «что менялось по объекту за неделю» и «кто снял объект с Авито».

## Действия (только с подтверждением)

- Создать/обновить подборку и вернуть короткую ссылку.
- Опубликовать или снять объект — на всех площадках или на одной (например, только Авито).
- Создать новый объект и заполнить карточку по описанию.
- Изменить цену, статус, комиссию, депозит, условия.
- Добавить, перенести или отменить бронь; создать аренду.
- Завести клиента, обновить данные, поставить/снять чёрный список.
- Изменить статус заявки.

Порядок: Ассистент показывает карточку «что будет сделано» → вы нажимаете «Подтвердить» → изменение применяется и попадает в журнал.

## Чтобы новые функции сразу были доступны Ассистенту

Инструменты собираются из одного реестра (`src/lib/ai/tools/index.ts`), который автоматически подхватывает все файлы из папки инструментов. Правило проекта: каждая новая функция RM OS одновременно с интерфейсом получает инструмент в этом реестре. Правило фиксируем в памяти проекта и в `AGENTS.md`, чтобы при обновлении системы Ассистент получал новые возможности сам.

## Каналы команд

1. Чат в RM OS (`/assistant`) — основной, история диалога сохраняется.
2. Telegram-бот «Ассистент» — те же команды, подтверждения кнопками. Нужен токен от @BotFather.

## Технические детали

- Модель — `openai/gpt-6-astra` через шлюз Lovable AI, потоковый ответ.
- Инструменты — AI SDK `tool()` с Zod-схемами; изменяющие помечены `destructiveHint` и всегда проходят подтверждение.
- Новые таблицы: `activity_log` (журнал), `ai_action_proposals` (предложенные действия), `assistant_messages` (история диалога), `telegram_links` (привязка Telegram к пользователю RM OS). Все с RLS для авторизованных пользователей.
- Запись в журнал — триггерами базы на основных таблицах, чтобы попадали и правки из интерфейса, и действия Ассистента.
- Telegram webhook: `POST /api/public/telegram` с проверкой секретного токена.
- Секреты: `LOVABLE_API_KEY` (есть), `TELEGRAM_BOT_TOKEN` (нужен), опционально `AI_HTTPS_PROXY` для сервера РФ.

## Порядок работ

1. Проверка доступности шлюза ИИ с сервера РФ.
2. Журнал действий (`activity_log`) и триггеры.
3. Реестр инструментов + чтение всех данных, включая журнал.
4. Подтверждение действий.
5. Изменяющие инструменты (подборки, публикации, объекты, брони, клиенты, заявки).
6. Переименование в «Ассистент» и голубое сияние кнопки.
7. Telegram-бот.
