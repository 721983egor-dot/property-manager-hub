# Интеграция ЦИАН в RM OS

Начинаем с ЦИАН: сначала подтягиваем уже размещённые объявления и связываем их с объектами в RM OS, дальше новые объекты уходят на ЦИАН автоматически. Авито — следующим этапом по той же схеме.

## Этап 1. Подключение кабинета ЦИАН

- Экран «Настройки → Площадки» с полем для ключа доступа ЦИАН.
- Ключ выдаётся в личном кабинете ЦИАН для профессионалов; он хранится в защищённом хранилище проекта, а не в коде.
- Кнопка «Проверить подключение» — показывает, к какому аккаунту мы подключились и сколько там объявлений.

## Этап 2. Сопоставление уже опубликованных объявлений

Разовая операция, запускается кнопкой «Загрузить объявления с ЦИАН» в разделе «Публикация и реклама».

1. Забираем список всех активных объявлений аккаунта: ID, адрес, ЖК, площадь, комнаты, цена, ссылка, фото.
2. Автоматически подбираем пару к объекту RM OS: сначала по адресу + площади + числу комнат, затем по названию ЖК + комнатам + цене.
3. Показываем экран сверки:
   - «Совпало точно» — сразу связываем;
   - «Похоже, но надо проверить» — выпадающий список кандидатов, менеджер подтверждает;
   - «Нет объекта в RM OS» — предложение создать объект из данных объявления;
   - «Есть в RM OS, но нет на ЦИАН» — попадёт в очередь на публикацию.
4. После подтверждения в `property_listings` для платформы `cian` записываются `external_id`, `external_url`, `published = true`, дата публикации.

Связь ставится один раз; дальше синхронизация идёт по `external_id`.

## Этап 3. Автоматическая публикация новых объектов

- В карточке объекта в `/promo` кнопка «Опубликовать на ЦИАН» становится рабочей.
- Новый объект в RM OS с заполненными обязательными полями можно отправить на ЦИАН одним нажатием; при желании включается режим «публиковать автоматически при добавлении».
- Изменение цены, описания, фото или статуса в RM OS обновляет объявление на ЦИАН.
- «Снять с публикации» — снимает объявление.
- Перед отправкой проверяем обязательные для ЦИАН поля (адрес, площадь, этаж, цена, фото) и показываем понятный список того, что нужно дозаполнить.

## Этап 4. Статистика и обращения

На странице объекта в `/promo` рядом с блоком сайта РМ появляются данные ЦИАН за выбранный период (7 / 30 / 90 дней):
- показы в выдаче и просмотры объявления;
- просмотры контактов;
- звонки;
- сообщения из чата ЦИАН, привязанные к объявлению.

Обновление — по кнопке «Синхронизировать», плюс автоматически раз в сутки.

## Технические детали

**База данных (одна миграция):**
- `platform_credentials` — ключ доступа и параметры аккаунта по каждой площадке (`platform`, `account_label`, `connected_at`), сам секрет в хранилище секретов.
- `property_listings` уже поддерживает `cian` — заполняем `external_id`, `external_url`, `published`, `published_at`, `last_synced_at`; добавляем `sync_status` и `sync_error` для показа проблем публикации.
- `listing_stats` — `property_id`, `platform`, `date`, `impressions`, `views`, `contact_views`, `calls`, уникальность по (property_id, platform, date).
- `listing_messages` — `property_id`, `platform`, `external_chat_id`, `author`, `text`, `sent_at`.
- GRANT + RLS по правилам проекта.

**Код:**
- `src/lib/cian.ts` — типы, маппинг полей RM OS → ЦИАН.
- `src/lib/cian.functions.ts` — серверные функции: `testCianConnection`, `importCianListings`, `linkCianListing`, `publishToCian`, `unpublishFromCian`, `syncCianStats`, `syncCianMessages`.
- `src/routes/promo.import.tsx` — экран сверки объявлений.
- `src/routes/api/public/cron/cian-sync.ts` — ежедневная синхронизация статистики (по секрету).
- Обновление `src/routes/promo.index.tsx` и `src/routes/promo.$id.tsx`: рабочие кнопки ЦИАН, блоки статистики и сообщений вместо «Скоро».
- Все обращения к ЦИАН только с сервера, ключ в браузер не попадает.

## Что нужно от вас

1. Доступ к API в кабинете ЦИАН (обычно включается для профессионального аккаунта; при необходимости — заявка в поддержку ЦИАН).
2. Ключ доступа — я попрошу его через защищённую форму, когда дойдём до подключения.
3. Проверить результаты сверки объявлений: часть пар придётся подтвердить вручную.

## Риски

- Доступ к API ЦИАН выдаётся не всем аккаунтам — это первое, что проверим.
- Часть объявлений может не сопоставиться автоматически, если адрес на ЦИАН заполнен иначе, чем в RM OS.
- Состав статистики зависит от тарифа кабинета: покажем то, что реально отдаёт площадка.
