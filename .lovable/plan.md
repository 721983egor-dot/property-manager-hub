# Сообщения ЦИАН в чате RM OS

Да, переписка с покупателями на ЦИАН доступна по их API — мы уже читаем список чатов, чтобы подтягивать карточки объявлений. Значит, можно показывать эти диалоги прямо в разделе «Чаты» RM OS вместе с обращениями с сайта.

## Как это будет выглядеть

- В разделе «Чаты» у каждого диалога появляется отметка источника: «Сайт» или «ЦИАН».
- Диалог с ЦИАН открывается так же, как обычный: имя собеседника, история сообщений, время, непрочитанные.
- Если чат привязан к конкретному объявлению — в шапке диалога видно, о каком объекте речь, со ссылкой на карточку объекта.
- Ответ менеджера из RM OS уходит собеседнику в ЦИАН (если площадка разрешает отправку по нашему ключу; проверю первым делом — если нет, диалог будет только на чтение и мы честно это подпишем).
- Обновление: автоматически по расписанию (то же ежедневное задание на сервере плюс частый интервал в рабочее время) и кнопкой «Обновить» в списке чатов.
- Ассистент видит эти переписки наравне с остальными данными и может по ним отвечать на вопросы.

## Что нужно проверить в начале

1. Отдаёт ли ключ ЦИАН доступ к отправке сообщений, а не только к чтению.
2. Хватает ли лимитов на регулярное чтение чатов.

Если отправка недоступна — сообщения всё равно попадут в RM OS, отвечать придётся в кабинете ЦИАН; напишу об этом прямо в интерфейсе.

## Технические детали

**База (одна миграция):**
- `chat_threads`: добавить `source` (`site` | `cian`, по умолчанию `site`), `external_id` (id чата площадки), `external_offer_id`, `property_id`; уникальность по (`source`, `external_id`).
- `visitor_key` сделать необязательным для внешних источников (или заполнять значением `cian:<chatId>`).
- `chat_messages`: добавить `external_id` для защиты от дублей и уникальный индекс (`thread_id`, `external_id`).
- GRANT + RLS по правилам проекта.

**Код:**
- `src/lib/cian.server.ts` — уже есть `fetchChats` и `fetchChatMessages`; добавить `sendChatMessage` (после проверки метода в API).
- `src/lib/cian-chats.server.ts` — синхронизация: чаты → `chat_threads`, сообщения → `chat_messages` (`direction` по автору), связка с объектом через `property_listings.external_id`.
- `src/lib/chat.functions.ts` — при ответе в тред с `source = 'cian'` отправлять сообщение в ЦИАН, иначе как сейчас.
- `src/routes/api/public/cron/cian-sync.ts` — добавить синхронизацию чатов к синхронизации статистики.
- `src/routes/_authenticated/chats.index.tsx` — бейдж источника, объект в шапке, кнопка «Обновить».
- Ассистент: чтение чатов площадок в `src/lib/ai/tools/read.server.ts`, отправка ответа — через подтверждаемое действие в `mutate.server.ts` + `executors.server.ts`, регистрация в реестре инструментов.
