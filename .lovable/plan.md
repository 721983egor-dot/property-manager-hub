# Диагностика: превью отдавало «Internal server error»

## Что выяснено

- Код приложения исправен: локальная сборка — `build OK`, dev-сервер отдаёт страницу (HTTP 200), список из 4 объектов рендерится, ошибок в консоли нет.
- В серверных логах превью ровно одна ошибка (14:28:57 UTC): временный сбой инфраструктуры превью-сервера — превышен лимит одновременных чтений при загрузке превью-сборки (ошибка платформы, не приложения). Ответ был 502, что в интерфейсе выглядело как «Internal server error».
- Новых ошибок после этого момента в логах нет — сбой единичный и, скорее всего, уже прошёл.

## План

1. Обновить страницу превью — приложение должно открыться без каких-либо изменений кода.
2. Если ошибка «Internal server error» повторится после обновления:
   - перезапустить превью-окружение (dev-сервер) и повторно проверить логи;
   - при повторении платформенной ошибки чтения — подождать несколько минут и повторить, т.к. это временный лимит инфраструктуры.

Изменений в коде не требуется.
