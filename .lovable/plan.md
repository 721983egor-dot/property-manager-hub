# Добавить «Студия» в планировку для квартир/апартаментов

## Что делаем

Добавляем в поле «Планировка» вариант «Студия». Он будет доступен только при типе объекта «Квартиры и Апартаменты». Для «Дома и Виллы» и «Таунхаус» вариант «Студия» не показывается.

## Почему `rooms = 0`

Колонка `properties.rooms` уже есть (`integer NOT NULL DEFAULT 1`), без `CHECK >= 1`. Используем значение `0` как внутренний признак студии — это не требует миграции базы и сохраняет тип целым числом.

## Изменения

1. `src/lib/properties.ts`
   - Включить `0` в `ROOM_OPTIONS`.
   - Доработать `roomsLabel(0)`: вернуть «Студия».
   - Доработать отображение в зависимых местах (property card — `bedroomsLabel`).

2. `src/components/PropertyForm.tsx`
   - В селекте «Планировка» показывать опцию «Студия» (`0`) только когда `!isHouse`.
   - Для домов/вилл/таунхаусов оставить только 1–8 комнат.

3. `src/routes/index.tsx`
   - В фильтре «Планировка» добавить «Студия» (`0`).
   - Оставить работу фильтра по числовому сравнению `p.rooms !== Number(rooms)`.

4. `src/components/site/PropertyCard.tsx`
   - Обновить `bedroomsLabel`, чтобы `0` отображалось как «Студия».

5. Проверить TypeScript и сборку.

## Что НЕ меняем

- Не добавляем отдельную колонку `is_studio`.
- Не меняем логику домов/вилл.
- Не трогаем фильтр статусов, архив, карточку preview и CRM.
