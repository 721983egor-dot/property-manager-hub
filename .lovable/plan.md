# Перенос объектов с сайта residence-more.ru в RM OS

## Суть

На странице https://residence-more.ru/rent найдено 33 ссылки: 31 отдельный объект и 2 раздела-комплекса («Лазурный берег 1» и «Лазурный берег 2»), внутри которых свои квартиры.

Прохожу по каждой ссылке, забираю данные и создаю объекты (и нужные комплексы) в RM OS. Синхронизация календаря с площадками пока не делается.

## Что забираю с сайта

- Название карточки
- Тип объекта (апартаменты, квартира, дом/вилла, таунхаус)
- Комплекс/ЖК
- Адрес (короткий, для карты)
- Координаты из карты
- Площадь
- Количество спален, комнат, санузлов
- Этаж и этажность
- Цена в месяц
- Летняя цена (июнь — сентябрь), если указана
- Страховой депозит
- Статус (свободен сейчас)
- Техника, дополнительные характеристики
- Описание
- Локация
- Условия аренды
- Фотографии галереи

## Что создаю в RM OS

### Объекты

- Каждый URL станет отдельной строкой в `properties`.
- Объекты создаются опубликованными (`published = true`), статус — свободен.
- Добавляю поле `source_url` (уникальное, nullable) — чтобы не задваивать при повторном переносе.
- 4 существующих демо-объекта не трогаю.

### Комплексы

- Для «Лазурный берег 1» и «Лазурный берег 2» создаю записи в `complexes` и привязываю их квартиры по `complex_id`.
- Для остальных объектов, у которых на сайте указан комплекс, тоже создаю или переиспользую запись `complexes` по названию.

### Фотографии

- Скачиваю фото с сайта, загружаю в бакет `property-photos`.
- Первое фото делаю главным.
- Пути записываю в `photos` как обычные внутренние пути.

## Результат

- Список созданных объектов: что удалось перенести полностью, что — с частичными данными.
- Список созданных комплексов.
- Отчёт по недостающим полям (например, этаж, депозит, точный адрес), чтобы вы могли дозаполнить вручную.

## Технические детали

- Разовый импорт скриптом на моей стороне: постраничный разбор HTML Tilda, сопоставление полей, скачивание изображений, вставка в базу.
- Новая сущность не создаётся; используются существующие `properties` и `complexes`.
- `source_url` добавляется миграцией к `properties` для предотвращения дублей.
