# ИИ-помощник в РМ ОС

## Что появится

Новый раздел «Помощник» в РМ ОС — чат с ИИ, который понимает русский, знает вашу базу объектов, броней, заявок и статистику площадок, и умеет по команде выполнять действия — каждое действие только после вашего подтверждения кнопкой.

## Возможности

1. **Анализ и отчёты** — «сколько просмотров за неделю по площадкам», «какие объекты без заявок за 30 дней», «топ-5 объектов по звонкам», сводка по бронированиям и заселению.
2. **Проверка данных** — «найди объекты с незаполненными полями», «что мешает публикации на ЦИАН/Яндекс», дубли клиентов по телефону, объекты без фото/цены.
3. **Действия с объявлениями (с подтверждением)** — ИИ показывает карточку «Опубликовать объект 1041 на ЦИАН?» → вы жмёте «Подтвердить» или «Отмена». Действия: публикация/снятие на площадках, смена цены, смена статуса объекта. Без подтверждения ИИ ничего не меняет.

## Как устроено (техническая часть)

- **Страница** `src/routes/assistant.index.tsx` — чат: лента сообщений, поле ввода, отображение «думает», карточки действий с кнопками подтверждения. Пункт «Помощник» в боковом меню РМ ОС. Рендер ответов через `react-markdown`.
- **Серверный чат-эндпоинт** `src/routes/api/assistant.ts` — потоковый ответ через Lovable AI (модель по умолчанию из каталога шлюза). Системный промпт: роль «помощник менеджера агентства аренды Residence More», правила (действия только через инструменты подтверждения, отвечать по-русски, цифры — из базы, не выдумывать).
- **Инструменты чтения** (AI SDK tools, исполнение на сервере через Supabase):
  - `searchProperties` — поиск объектов (по названию, статусу, типу, району);
  - `getPropertyDetails` — карточка объекта с проверкой полноты полей и готовности к площадкам (`missingCianFields`/`missingYandexFields`);
  - `getListingStats` — статистика просмотров/звонков/сообщений по площадкам и периодам;
  - `getLeadsSummary`, `getBookingsSummary` — сводки по заявкам и броням.
- **Инструменты действий** — `proposeAction(type, payload)`: не выполняет изменение, а возвращает в чат карточку подтверждения. Кнопка «Подтвердить» вызывает существующие серверные функции (`setCianPublished`, `setYandexPublished`, обновление объекта через `properties.ts`).
- **История чата** — хранится в новой таблице `assistant_messages` (миграция: таблица + GRANT + RLS для authenticated), на каждый запрос отправляется полная история.
- **Пакеты**: `ai`, `@ai-sdk/openai`, `react-markdown`.

## Безопасность и ключи

- Ключ ИИ хранится на сервере, в браузер не попадает.
- Раздел доступен только авторизованным пользователям РМ ОС.
- Пишущие операции ИИ не выполняет сам — только кнопка подтверждения.

## Проверка

Прогон тестового диалога: вопрос по статистике → запрос списка проблемных объектов → команда «опубликуй …» → карточка подтверждения → подтверждение и проверка результата в базе.
