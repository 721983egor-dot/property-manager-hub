# Яндекс.Карты в объектах

Подключаем подсказки адресов при вводе и карту с меткой по адресу объекта.

## Что появится

**В форме создания/редактирования объекта**
- Поле «Адрес» превращается в поле с автодополнением: по мере ввода выпадает список реальных адресов из Яндекса.
- При выборе адреса из списка он подставляется целиком, а координаты метки сохраняются вместе с объектом.
- Под полем — мини-карта с меткой, метку можно перетащить, если точка встала неточно.
- Можно ввести адрес руками, без выбора из списка: тогда координаты определяются автоматически по тексту адреса при сохранении.

**В карточке объекта в RM OS**
- Блок «Адрес» получает встроенную карту с меткой; ссылка «Открыть в Яндекс.Картах» остаётся.

**На публичной странице /rent/$id**
- В блоке локации вместо статичной ссылки — карта с меткой в стилистике страницы (та же тёмно-синяя/золотистая палитра, скруглённые углы), ссылка на Яндекс.Карты сохраняется.

Если у объекта координат ещё нет и адрес не распознан, карта не показывается — остаётся текст адреса и ссылка, как сейчас.

## Технические детали

1. **Секреты**: попрошу через диалог добавления ключей два значения — ключ JavaScript API + Геокодер и ключ API Геосаджеста. Ключ Геосаджеста используется только на сервере.
2. **Миграция**: в `properties` добавляются `latitude numeric` и `longitude numeric` (nullable). Существующие объекты остаются без координат, координаты подтягиваются при первом сохранении/геокодировании.
3. **Подсказки**: серверная функция `suggestAddress` (`src/lib/geo.functions.ts`) проксирует запрос к `suggest-maps.yandex.ru/v1/suggest` с серверным ключом — ключ не попадает в браузер. Вызов с дебаунсом 300 мс из формы.
4. **Геокодирование**: серверная функция `geocodeAddress` обращается к `geocode-maps.yandex.ru/1.x` и возвращает широту/долготу. Используется при выборе подсказки и при сохранении адреса, введённого вручную.
5. **Карта**: компонент `src/components/YandexMap.tsx` — клиентский, грузит JS API скриптом с ключом, монтируется только на клиенте (`ClientOnly`/динамический импорт), рисует одну метку. Ключ JS API отдаётся отдельной серверной функцией `getMapsApiKey` (он публичный по природе, ограничивается доменом в кабинете Яндекса).
6. **Типы и слой данных**: `Property`, `PropertyInput`, нормализация и формы в `src/lib/properties.ts` расширяются полями координат.

## Порядок работ

1. Запросить ключи, добавить миграцию с координатами.
2. Серверные функции: подсказки, геокодер, выдача ключа карт.
3. Автодополнение адреса + мини-карта в `PropertyForm`.
4. Карта в карточке объекта RM OS и на публичной странице.
5. Проверка: сборка, типы, реальный ввод адреса и отображение метки в превью.
