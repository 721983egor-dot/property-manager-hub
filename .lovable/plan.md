# Яндекс Недвижимость: публикация через XML-фид + статистика

## Идея
По аналогии с ЦИАН: объекты из RM OS попадают на Яндекс Недвижимость автоматически, кнопки «Опубликовать» / «Снять» управляют присутствием объекта в фиде, статистика просмотров подтягивается через партнёрский API (токен уже сохранён).

## Как будет для менеджера
- В «Публикация и реклама» — кнопки «Опубликовать» / «Снять» для Яндекс Недвижимости, как у ЦИАН.
- Если данных не хватает — под кнопкой список, что дозаполнить.
- Отдельная галочка «Публиковать новые объекты автоматически» для Яндекса.
- На странице объекта в рекламе — статистика Яндекса (просмотры и др. по возможности API).

## Что делаем
1. **XML-фид YRL** — новый адрес `/api/public/feeds/yandex.xml` в формате Яндекса (YRL: `offer`, категории аренды, `price`, `area`, `rooms`, `floor`, `image`, `description`). Ссылку вставляем в кабинете Яндекс Недвижимости.
2. **Фото** — переиспользуем готовый раздающий адрес `/api/public/feed-photo/…` от ЦИАН.
3. **Управление публикацией** — `property_listings` с платформой `yandex_realty`: `published` = «в фиде», `unpublished_at`, `sync_status`, `sync_error`.
4. **Проверка полей** — функция `missingYandexFields` по требованиям фида (адрес, площадь, цена, этаж, фото, описание).
5. **Статистика** — серверная функция опроса партнёрского API Яндекса (токен `YANDEX_REALTY_TOKEN`): просмотры/обращения за 7/30/90 дней, кнопка «Синхронизировать», хранение в `platform_stats`-стиле (как ЦИАН). Если API не отдаст метрику — честно покажем только доступное.
6. **Интерфейс** — блок настроек площадки «Яндекс Недвижимость»: ссылка на фид с «Скопировать», галочка автопубликации, инструкция.

## Технические детали
- `src/routes/api/public/feeds/yandex[.]xml.ts` — генерация YRL из объектов с `property_listings.published=true` (платформа `yandex_realty`), `Cache-Control` ~5 мин.
- `src/lib/yandex-feed.server.ts` — `buildYandexFeedXml`, переиспользует фото-роут.
- `src/lib/yandex-realty.functions.ts` — `setYandexPublished`, `setYandexAutoPublish`, `getYandexFeedInfo`, `syncYandexStats` (вызов API с `Authorization: OAuth …`).
- `src/lib/yandex.ts` — `missingYandexFields`.
- Обновить `promo.index.tsx`, `promo.$id.tsx`, `promo.import.tsx` (блок настроек площадки).
- Миграций не нужно: `platform_credentials.auto_publish` уже есть, платформа хранится строкой в `property_listings`.

## Потребуется от вас
1. В кабинете Яндекс Недвижимости подключить загрузку по фиду и вставить ссылку (дам готовую).
2. После первой загрузки — прислать отчёт об ошибках, если будут.

## Проверка
- Фид отдаётся, валидные YRL-теги, объект без цены в фид не попадает.
- Публикация/снятие кнопкой меняет содержимое фида.
- Синхронизация статистики с реальным токеном — проверим ответ API и покажем, что доступно.
