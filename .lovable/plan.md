# Сделки: клиенты, показы и закрытие сделки

## 1. Новый клиент прямо из сделки
- В карточке сделки рядом со списком «Клиент» появится кнопка «+ Новый».
- Она открывает привычную форму клиента (ФИО, телефон, комментарий). После сохранения клиент сразу подставляется в сделку.

## 2. Сделки в карточке клиента
- В карточке клиента добавится блок «Сделки»: сначала открытые, ниже — успешные и отказы.
- В каждой строке: название, стадия, объект, даты аренды и бюджет. Клик открывает сделку.

## 3. Единая лента в карточке сделки
- Вкладки «Комментарии» и «История» объединяются в одну ленту плитками, как на присланном скриншоте.
- Плитки разных типов: комментарий сотрудника, изменение полей, показ объекта, смена стадии, закрытие сделки.
- Наверху ленты остаётся поле для нового комментария; фильтр «Все / Комментарии / История».

## 4. Показы объектов
- Когда сделка на стадии показа, в карточке появляется блок «Показы»: выбрать объект, дату и заметку.
- Каждый показ сохраняется и попадает в ленту отдельной плиткой; показ можно удалить.

## 5. Логика успешного закрытия
При переводе сделки в стадию с типом «Успешно» открывается окно закрытия, где все поля обязательны:
- объект;
- даты заезда и выезда;
- цена в месяц;
- депозит;
- комиссия (если у объекта она есть — подставляется из карточки объекта);
- число ежемесячной оплаты.


Дальше по типу услуги объекта:
- **Управление**: создаётся бронирование в календаре на эти даты с данными клиента, объект получает статус «Сдан».
- **Только комиссия**: бронирование в календарь не ставится, объект переходит в статус «Сдан», а даты заезда и выезда сохраняются в сделке и видны в карточке клиента.

В обоих случаях в ленту сделки пишется плитка «Сделка закрыта: объект, даты», а изменения попадают в общий журнал.

## Технические детали
- Миграция: таблица `deal_showings` (`deal_id`, `property_id`, `shown_at`, `note`) с RLS как у `deal_comments` и триггером журнала; колонки `deals.start_date`, `deals.end_date`, `deals.closed_property_id`.
- `src/lib/deals.ts`: функции показов, закрытия сделки (`closeDealAsWon`), выборка сделок клиента.
- `src/components/DealTimeline.tsx` → единая лента плиток из комментариев + `activity_log` + показов.
- Новые компоненты: `DealShowings`, `DealWonDialog`; `ClientDialog` получает колбэк `onSaved(clientId)`.
- Закрытие через управление использует существующие `saveBooking` и `markPropertyRented`.
- Ассистент по правилу проекта получает: чтение показов и закрытий (`read.server.ts`), подтверждаемые действия «добавить показ» и «закрыть сделку» (`mutate.server.ts` + `executors.server.ts`, регистрация в `index.server.ts`).
