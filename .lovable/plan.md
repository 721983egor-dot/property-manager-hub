# Единые данные для сотрудников в RM OS

## Что исправлю
- Переведу загрузку бронирований и связанных клиентов в календаре на защищённое чтение для сотрудников, как уже сделано для объектов и клиентов.
- Администратор и менеджер будут видеть одинаковые объекты, комплексы, клиентов и бронирования; ограничения останутся только на действия изменения и удаления.
- Скрытые в архив объекты исключу из календаря. При удалении объекта его строка и связанные с ней записи больше не будут отображаться.
- После создания бронирования календарь будет обновляться сразу у текущего сотрудника, а у остальных — после автоматического обновления данных или повторного открытия страницы.
- Проверю календарь, данные клиента в брони, сборку и работу на мобильном экране.

## Права доступа
- Менеджер: просмотр всех данных календаря и клиентов, создание нового бронирования.
- Администратор: полный доступ, включая редактирование, архивирование и удаление.
- Защищённые персональные данные клиентов не станут публичными.

## Технические детали
- Добавлю серверные функции чтения бронирований, периодов цен, комплексов и связанных клиентов с обязательной проверкой роли сотрудника.
- Общие запросы календаря будут использовать единый защищённый источник данных, не зависящий от различий прав базы на российском сервере.
- В выборке календаря будут только неархивные объекты; удалённые объекты исчезнут автоматически из-за отсутствия основной записи.
