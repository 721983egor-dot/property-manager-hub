# Новый раздел «Публикация и реклама»

Раздел «Объекты» остаётся для менеджеров без изменений. Рядом появляется отдельный раздел, где видно, где каждый объект опубликован, и сколько его смотрят.

## Что появится

**Список объектов для публикации**
- Карточки объектов: фото, название, ЖК, цена, статус.
- В каждой карточке три площадки: Сайт РМ, Авито, ЦИАН — с меткой «Опубликовано / Не опубликовано» и датой публикации.
- Кнопка «Опубликовать» / «Снять с публикации» для сайта РМ работает сразу (это та же публикация, что и галочка в карточке объекта, плюс запоминается дата и время).
- Кнопки Авито и ЦИАН пока помечены «Скоро» — интерфейс готов, подключение по API сделаем позже.
- Фильтры: опубликованные на сайте / не опубликованные, поиск по названию и ЖК.

**Страница объекта в этом разделе**
- Блок «Где опубликовано» с тремя площадками и датами.
- Блок «Статистика за период» с выбором периода (7 дней, 30 дней, произвольный):
  - просмотры страницы объекта на сайте;
  - заявки и клики по контактам (позвонить / написать) с этого объекта;
  - добавления объекта в клиентские подборки;
  - простой график по дням.
- Заготовленные блоки статистики Авито и ЦИАН с пометкой «Не подключено».

**Сбор статистики на сайте**
Начнём считать события на публичных страницах: открытие страницы объекта, клик по кнопкам связи, отправка заявки, добавление в подборку. Данные считаются анонимно, без персональных данных; повторные открытия одной страницы одним посетителем в течение 30 минут не удваиваются.

Важно: статистика начнёт накапливаться с момента запуска — за прошлые месяцы цифр не будет.

## Техническая часть

- Миграция: таблица `property_events` (property_id, event_type, occurred_at, visitor_hash, source, referrer) с индексами по property_id + occurred_at; INSERT разрешён anon (только вставка), чтение — authenticated/anon по текущей модели доступа; таблица `property_listings` (property_id, platform: site|avito|cian, published, published_at, external_id, external_url, last_synced_at) с уникальностью property_id+platform. GRANT + RLS по правилам проекта.
- Запись событий — через серверную функцию `src/lib/analytics.functions.ts` (публичная, с валидацией типа события и rate-нейтральной дедупликацией по visitor_hash), вызывается из `rent.$id.tsx`, `PropertyPublicPage`, `SiteLeadForm`, `p.$code.tsx`.
- Чтение агрегатов — серверная функция с группировкой по дню за период; график на recharts.
- Новые роуты: `src/routes/promo.index.tsx` и `src/routes/promo.$id.tsx`; префикс `/promo` добавляется в `CRM_PREFIXES` в `AppShell.tsx` и в боковое меню (иконка Megaphone).
- Публикация на сайт пишет `properties.published` и `property_listings` для платформы `site` в одной операции.
- Слой площадок Авито/ЦИАН описан интерфейсом-адаптером, чтобы позже подключить API без переделки экранов.

## Ответ на вопрос про статистику

Да — по каждому объекту за выбранный период будут видны просмотры страницы, обращения (заявки и клики по контактам) и попадания в подборки. Дополнительно можно позже добавить источники переходов и конверсию «просмотр → заявка».
